# Version 0.6 stability qualification

Qualified on Windows on 28 October 2026 with Codex CLI 0.164.0-alpha.11.1 and existing ChatGPT authentication. No API billing fallback is used. Private manifests, native IDs, histories and detailed command receipts are retained outside the public distribution.

## Repairs and observed behavior

- Same designated owner can refresh a changed integration policy at an idle boundary with `coordinator_register`, without restarting the desktop. Revoked/foreign owners and unresolved execution remain refused. Operator updates preserve existing integrations and attachment mode unless deliberately replaced.
- Idle external writer conflicts are classified before turn dispatch. Coordinators can allocate an appropriate project successor with context handoff and independent auditing, preserving the locked original and prior attempt.
- Explicit `git-write` allows local index/commit operations only in a writer's own normal repository. Native operations proved ordinary writer denial, authorized add/commit success, and auditor/foreign/revoked denial. Linked metadata remains outside this capability.
- Native Git inspection cannot inherit the MCP input pipe; inspection is bounded. This fixes a reproduced persistent-stdio startup hang.
- Native resume ignores overrides on an already loaded worker. The plugin unsubscribes only its own idle worker and appends current registry-derived scope through the native history API. Original history remains intact; uncertain context changes retain a lifecycle fence.
- Default-enabled plugin MCPs absent from config are inventoried and explicitly disabled per embedded server. The native catalogue verified no integrations by default, Blender/Godot for their grant, and Node/CUA for their grant, without unrelated Data/key-helper exposure. Discovery executed no editor or browser action.

## Qualification performed

The automated suite has **172 passing tests**. It includes the mixed-version migration/handoff fences, grant preservation, native-writer envelopes, persistent Git input isolation, loaded-scope refresh, and uncertain-lifecycle recovery. Independent review also reproduced a concurrent stale operator update and a local Git timeout after the dispatch marker. Their regressions now require a transactional grant snapshot check and local policy validation before remote dispatch, preserving intervening revocations/UI changes and proving the timeout was undispatched.

A private two-project test used real MCP processes, native persistent Codex conversations and model turns. Both developers delivered tested local commits. An independent auditor rejected a deliberately introduced fixture defect; the original developer corrected it and the auditor accepted the new revision. The second project passed its own independent audit. Same-owner policy refresh, cross-project refusal, exact completed-key deduplication after owner restart, and terminal task acceptance were observed. All fixture workers/coordinators were archived while retaining their histories.

A further real auditor read registered artifacts, reported the current two-directory scope, then saw a newly registered third directory on the same conversation and reported the new count and actual file hash. Native history inspection confirmed the appended three-directory read-only scope. Earlier failed traces are retained and are not counted as successful qualification.

Windows MXC passed **20 small-file checks** across five grant/role states; local Git passed **six native operations**. Read-only version/data probes of existing CPU/CUDA Python installations passed. A real old bridge's native child was observed before and absent after its own idle release. Mixed-version stdio handoff uses real MCP processes/SQLite with synthetic remote metadata and turn replies; it is not a production-project handoff.

## Delivery gates and limits

The release requires independent review of the frozen candidate, public-file privacy checks, a clean-clone test/install into a credential-free profile, identical reinstall, installed helper checks, all 44 MCP tools, and Windows/Linux CI. These release gates are recorded against the release revision; fixture results alone do not establish that a changed candidate passed them.

Windows workers require MXC and fail without it. The plugin cannot release a desktop-owned writer through another connection, manufacture human product decisions, expand revoked permissions, or bypass subscription limits. This qualification does not certify GPU/CUDA execution, project business correctness, arbitrary editor/browser workflows, other devices, or native non-Windows sandbox behavior. Installation preserves loaded older connections; their original coordinators use the installed same-chat helper at an idle boundary. No production worker, benchmark or training workload was launched by these tests.
